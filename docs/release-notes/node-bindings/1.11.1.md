# Node Bindings 1.11.1

A patch release for the 1.11 line, shipped with `@xmtp/node-sdk` 6.1.1. There are no API changes.

## Highlights

- **TCP keep-alive no longer races the HTTP/2 PING**, and the probe interval is set explicitly.
- **The maximum group size is now 500 members** (was 250).

## Bug Fixes

### TCP keep-alive

The TCP keep-alive idle time was 16 seconds, the same as the HTTP/2 PING interval, so the operating system's keep-alive probe and the PING raced on every cycle. No probe interval was set, so on Windows the client passed a probe interval of 0 to the operating system. Both are suspects for idle streams that were reset about every 35 seconds on Windows.

- The TCP keep-alive idle time is now 60 seconds, well above one PING cycle (16 second interval plus 10 second timeout). On a healthy connection the operating system never sends a probe, and the HTTP/2 PING remains the dead-connection detector.
- The probe interval is now 10 seconds on every platform whenever TCP keep-alive is on.
- `XMTP_GRPC_TCP_KEEPALIVE_SECS` still sets the idle time, and `0` disables TCP keep-alive.

## Other Changes

- The maximum group size is now 500 members. It is checked when members are added by identity (`addMembersByIdentity`, `createGroupByIdentity`).
- `libxmtpVersion` reports 1.11.1.
