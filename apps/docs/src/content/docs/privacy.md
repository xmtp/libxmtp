---
title: Privacy policy
---

`docs.xmtp.org` uses Plausible analytics to measure overall website traffic.
These statistics help site contributors improve the documentation.

Plausible states that it uses no cookies or persistent visitor identifiers.
It stores event and session records to calculate website statistics. Its
dashboard shows aggregate statistics.

Plausible uses the IP address and User-Agent in each request to derive a daily
visitor identifier for one website and device. It does not store the raw IP
address or User-Agent string. The identifier does not track a visitor across
days, devices, or websites.

For the data Plausible collects and its stated handling practices, see the
[Plausible Data Policy](https://plausible.io/data-policy).

If you have any questions about this privacy policy, post to the [XMTP Technical Forums](https://community.xmtp.org/).
