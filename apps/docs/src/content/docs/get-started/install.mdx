Install the SDK for your platform. All SDKs use a backend URL. See [Create a client](/sdk/client/) for client options and [Run the backend](/get-started/run-the-backend/) if you operate the backend.

## Install a package

Browser SDK 8 is built from the checked-out source. Run
`dev/nix-shell 'just js build-browser-sdk'`, then pack the matched public product
at `target/sdk-packages/browser` with npm through `dev/nix-shell`. Keep its
generated source, WASM, and runtime assets together.

Choose your package manager for a published package. These commands install the Browser package. Replace
`@xmtp/browser-sdk` with `@xmtp/node-sdk` for a Node application.

<Tabs syncKey="pkg">
<TabItem label="npm">

```sh
npm install @xmtp/browser-sdk
```

</TabItem>
<TabItem label="pnpm">

```sh
pnpm add @xmtp/browser-sdk
```

</TabItem>
<TabItem label="yarn">

```sh
yarn add @xmtp/browser-sdk
```

</TabItem>
<TabItem label="bun">

```sh
bun add @xmtp/browser-sdk
```

</TabItem>
</Tabs>

Use the package for your platform:

| Platform | Package or dependency           |
| -------- | ------------------------------- |
| Browser  | `@xmtp/browser-sdk`             |
| Node     | `@xmtp/node-sdk`                |
| Kotlin   | `org.xmtp:android`              |
| Swift    | Swift package product `XmtpSdk` |

The Browser and Node package commands above are the JavaScript package examples. For Android, add the XMTP Maven artifact to your app module:

```kotlin
android {
    compileOptions {
        sourceCompatibility = JavaVersion.VERSION_17
        targetCompatibility = JavaVersion.VERSION_17
        isCoreLibraryDesugaringEnabled = true
    }
}
dependencies {
    implementation("org.xmtp:android:<version>")
    coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.1.5")
}
```

Replace `<version>` with the matching 8.0.0 SDK version you built or released.
Import `uniffi.xmtp_sdk.*`. Keep the generated sources and JNI libraries from
the same build. An older network SDK cannot use this backend.

For Swift, the package manifest is at the root of
[libxmtp](https://github.com/xmtp/libxmtp). Add the `XmtpSdk` product to your app.
When using the self-hosted source branch, build its matching native bindings
before adding the local package in Xcode:

```sh
git clone --branch self-hosted https://github.com/xmtp/libxmtp.git
cd libxmtp
dev/nix-shell 'just ios build'
```

These repository commands require the Nix development environment. In a Swift
package next to that checkout, add these dependency and target entries:

```swift
// In Package.dependencies:
.package(path: "../libxmtp")

// In your app target's dependencies:
.product(name: "XmtpSdk", package: "libxmtp")
```

Use a matching published SDK and native binary after the self-hosted release is
available. A remote branch dependency alone does not build the native bindings.

## Platform prerequisites

<Tabs syncKey="sdk">
<TabItem label="Browser">

Use Node.js 22 or later for package tooling and a bundler that supports WebAssembly.
The Browser SDK stores its database in browser storage and does not encrypt it.
`dbEncryptionKey` is ignored by the Browser SDK.

</TabItem>
<TabItem label="Node">

Use Node.js 22 or later. Keep the 32-byte `dbEncryptionKey` and the database path
stable between launches.

</TabItem>
<TabItem label="Kotlin">

Use Android API 23 or later and Java 17 for the SDK build. Provide an Android
`Context`. Set `ClientOptions.backend` to
`BackendSource.Options(BackendOptions(url = backendUrl))`. Set the database
location and optional 32-byte key in `StorageOptions`. Call suspend methods
from a coroutine. End each client in `withContext(NonCancellable)`.

</TabItem>
<TabItem label="Swift">

Use Swift 6.1 or later. The package supports iOS 14 or later and macOS 11 or later.
Pass `BackendOptions(url:)` through `ClientOptions.backend`. Use
`StorageOptions` for the database location. Pass a securely generated or
caller-stored 32-byte `encryptionKey` for persistent storage. Keep the key and
reuse it when reopening the database. Omitting it selects unencrypted storage.
Call async methods from an async context.

</TabItem>
</Tabs>
